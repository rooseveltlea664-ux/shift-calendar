# 智巡排班 (ShiftMaster) - 智能双人协同排班与云端实时同步日历系统

一款专为个人、情侣、夫妻、值班搭档、医护及倒班人员打造的现代化、高颜值、以日历为中心的排班记录、双人协同管理与**云端跨设备实时自动同步** Web 系统。

---

## 🌟 核心特性与功能亮点

### 1. ☁️ 云端双人跨设备实时自动同步（新特性）
- **共享房间号机制**：双方只需设置相同的房间号（例如 `OUR-HOME`、`LOVE-888` 或一键随机生成），即可进入同一个协同空间。
- **双向即时同步**：
  - 任何一方在手机或电脑上调班、修改班次、添加备注或应用轮班，修改会**自动毫秒级推送到云端**。
  - 另一方的手机/电脑**实时自动接收更新**（支持 SSE 长连接即时推送 + 定时轮询 + 熄屏唤醒极速刷新），无需手动刷新页面！
- **🔗 一键专属邀请链接**：
  - 在「云端同步」弹窗中点击「一键复制链接」，通过微信/QQ 发送给对方。
  - 对方在手机浏览器中点击打开，**自动带入房间号并载入最新排班**，零操作门槛！

### 2. 👥 双人同屏排班对比与共同休息日智能识别
- **双人同屏排班对比**：日历每个日期格子同时清晰呈现两人的班次胶囊（如 `[我] 早班 8h` 与 `[TA] 休息 0h`），谁上班、谁在岗、谁休假一目了然。
- **🎉 共同休息日醒目高亮**：
  - 系统算法自动比对双方排班。当某一天两人均处于轮休/休假状态时，该日期格子将自动呈现**清新翠绿特殊高亮**并佩戴 **`🎉 同休`** 星标徽章！
- **✨ 月度共同休息日聚合清单**：
  - 右侧统计看板专门提供「共同休息」大卡片，汇总当月共同休息总天数。
  - 清晰列出当月所有两人同休的具体日期（如 `9月6日 周六 (周末)`、`9月14日 周日 (周末)`、`9月20日 周六`），并标注是否适逢周末，便于提前规划旅行、约会或家庭聚餐。
- **三重视图自由切换**：`👥 双人同看`（推荐）、`仅看【我】`、`仅看【TA】`。
- **双人称谓与标识定制**：支持自由修改双方昵称（如“老公/老婆”、“小明/小红”）及专属颜色。

### 3. 📅 现代化日历核心视图
- **月度全景日历**：以周一为起始日的标准 42 格日历布局，支持公历节日与「今日」动态高亮。
- **平滑年月切换**：快捷上一月/下一月、一键「回到今天」，以及年份月份快速精准跳转。
- **图例高亮筛选**：顶部图例栏支持点击任意班次，一键在日历中高亮该班次。

### 4. 🎨 自定义班次与自由组合轮班
- **自由增删改查**：自由定义任意工作班次，提供 18 款精选调色盘色彩 + 原生 Hex 取色器。
- **可视化轮班构建器**：可将任意班次自由拼接组合成循环链条（内置：四班三倒、两早两夜两休、三班轮倒、做一休一、标准上五休二等）。
- **双人分别/统一自动排班**：选定起始日期，可分别给两个人指定不同的轮班方案与起始天数偏移量，并提供未来 14 天对比预览条。

### 5. ✏️ 单日双人独立调班与备注
- **快捷双人调班**：点击任意日期，弹窗支持分别对【我】和【TA】的班次进行独立调整。
- **一键班次同步**：支持一键将对方的班次克隆给自己，快速对齐日程。
- **每日备注**：独立备注文本框与 8 款高频快捷标签，日历上显示醒目备注徽章。

### 6. 📊 强大的月度班次与双人统计功能
- **共同休息汇总看板**：共同休息天数统计、同休日期清单及双方出勤负荷对比。
- **双方出勤明细**：切换查看【我】与【TA】各班次出勤天数及工时占比进度条。

### 7. 💾 数据备份、导出与跨端同步
- **📱 导出手机日历 (ICS)**：一键同步到 iPhone 日历、安卓日历、Google Calendar 与 Outlook，**日程中清晰标出双方班次与【🎉 共同休息日】**！
- **📊 导出 Excel/CSV 报表**：导出包含双方班次、工时、备注及共同休息日列的规范表格。
- **🌓 深色/浅色双模式**：精心调配的夜间模式与白天模式。

## 🌐 外网访问与自动同步部署方案

本项目支持以下多种外网访问与同步部署方式：

### 方案 A：一键部署到免费云托管平台（推荐，永久免费、有公网域名）

#### 1. Vercel 极速部署（推荐）
本项目已内置 `vercel.json` 与 `api/sync.js`，完美兼容 Vercel Serverless：
1. 访问 [https://vercel.com](https://vercel.com) 并登录。
2. 导入本代码仓库（或拖拽文件夹部署）。
3. 部署完成后即可获得 `https://your-app.vercel.app`。
4. 打开网站，点击「☁️ 云端同步」，生成房间号并把链接发给对方，两人无论在何时何地均可实时双向同步！

#### 2. Render / Railway / Zeabur 一键部署
本项目内置了零依赖的原生 Node.js 服务端 `server.js` 与 `package.json`：
- 在 Render / Zeabur 上新建 Web Service，选择本仓库。
- 启动命令无需配置（自动运行 `node server.js`）。
- 部署成功后即可获得全球访问的 HTTPS 域名，自带 SSE 毫秒级长连接推送！

---

### 方案 B：在云服务器 (ECS / VPS / 宝塔面板) 上运行

如果您有自己的云服务器（腾讯云、阿里云等）：
1. 将本项目整个目录上传至服务器（例如 `/var/www/shift-calendar`）。
2. 在服务器上运行（无需 `npm install`，纯 Node 原生）：
   ```bash
   node server.js
   ```
   *(推荐使用 `pm2 start server.js --name shift` 后台持久运行)*
3. 在服务器防火墙/安全组放行 `3000` 端口，通过 `http://<服务器公网IP>:3000` 即可外网访问。
4. 如需配置域名与 SSL，可用 Nginx 反代 3000 端口并开启 HTTPS。

---

### 方案 C：从本地电脑穿透到公网 (免服务器即时测试)

如果希望网页直接运行在当前电脑上供外网访问：
1. 本地打开终端，运行：
   ```bash
   node server.js
   ```
2. 使用内网穿透工具映射本地 `3000` 端口：
   - **Cloudflare Tunnel (全球免费免备案)**：
     ```bash
     cloudflared tunnel --url http://localhost:3000
     ```
   - **cpolar (国内优化)**：
     ```bash
     cpolar http 3000
     ```
3. 将输出的公网链接发送给对方即可！
